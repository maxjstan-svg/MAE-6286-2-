Euler’s method

Euler’s method estimates the solution of a differential equation by taking small steps in the direction given by the current slope.

The idea: follow the slope

For an initial-value problem dy/dt = f(t, y), suppose we know the value at time tₙ. The equation gives the slope there. Treat that slope as constant across a short interval of length h, and use a straight line to estimate the next value.

yn+1 = yn + h f(tn, yn)Euler update · next value = current value + step size × current slope

Then move the time forward: tₙ₊₁ = tₙ + h. Repeating this update builds an approximate solution.

A simple example: cooling toward zero

Consider dy/dt = −y with y(0) = 1. The slope is the negative of the current value, so the solution decreases toward zero. In this case, the exact solution is y(t) = e−t.

Startt₀ = 0, y₀ = 1
Find the slopeAt y₀ = 1, the slope is −1.
Take a step of 0.2y₁ = 1 + 0.2(−1) = 0.8

The exact value at t = 0.2 is about 0.819, so this first Euler step is a little low.

Why use smaller steps?

With a smaller step, the slope changes less between updates, so each straight-line estimate usually tracks the curve more closely. The tradeoff is that reaching the same final time takes more steps. Euler’s method is simple and useful for learning and quick estimates; for demanding accuracy, higher-order methods are often preferred.
